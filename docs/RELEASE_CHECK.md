# 发布副本检查记录

本副本纳入 Git 的内容包含源码、教学素材、脱敏初始化数据、通用说明，以及经过隐私清理的微信小程序编译目录，未修改原运行项目。其他本机构建目录仍由 `.gitignore` 排除。

## 隐私清理

- 删除原 AI API Key 和数据库密码，改用环境变量或被 Git 忽略的本机配置文件。
- 清空原 DCloud、微信 AppID 和云函数示例中的应用标识。
- 管理员及学员改为虚构演示账号；原账号、密码、姓名、手机号、身份证号和邮箱未带入演示数据。
- 会话、学习足迹、考试记录、答题明细和错题记录的演示表为空。保留表结构，相关功能仍可产生新记录。
- 演示数据使用统一的虚构时间，空历史表自增序列重置。
- 排除 IDE 设置、微信私人配置、编译产物、依赖目录、本机审计、日志和备份。
- 移除文档及代码示例中的私人文件路径，不依赖原机器文档目录中的数据库启动脚本。
