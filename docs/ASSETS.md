# 教学素材说明

五个主题为账号安全、网络钓鱼、个人信息保护、设备与网络防护、备份与恢复。

- 主题插图由内置 image_gen 生成，导出为适合课程封面和轮播的压缩图片。提示词和相对保存路径见 [security-illustrations.json](security-illustrations.json)。其中没有保留生成机器的用户目录或本机文件路径。
- 标识源文件为 `docs/assets/security-mark.svg`；头像及考试提醒图采用代码绘制。
- 五段中文微课根据 `database/content/security-training.json` 的课程文案制作，包含分步画面和中文语音讲解，采用 H.264/AAC 格式，尺寸为 1280×720。
- 后端素材在 `backend/src/main/resources/static/upload/security/`，小程序内置图片在 `miniapp/static/security/`。原演示资源地址保留对应替换素材，以保持既有页面兼容。

这些制作记录仅说明素材来源，不替代对原模板及其余第三方资源的授权核对。
